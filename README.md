# control_detection

Experimental scripts and analyses for the **Control Detection** project — investigating how people detect their sense of agency and recognize items they interacted with.

This repository contains two experimental paradigms:

| Sub-experiment | Folder | Description |
|---|---|---|
| **CDmem** | `CDmem/` | Control detection + recognition memory (current main task) |
| **MTI** | `MTI/` | Multi-Timescale Inference — agency as a history-dependent process |

---

## CDmem — Control Detection & Memory

Participants watch moving shapes and decide which one they controlled. Afterward, they complete a **recognition memory test** for the image stimuli shown during the task.

See [`CDmem/README.md`](CDmem/README.md) for full details.

---

## MTI — Multi-Timescale Inference

A separate experiment testing whether agency detection reflects multi-timescale temporal integration, comparing Easy (2-shape) and Complex (4-shape) conditions.

See [`MTI/README.md`](MTI/README.md) for full details.
